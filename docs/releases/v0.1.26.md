# PicView v0.1.26

- 「顯示子資料夾」、「上一層資料夾」與「返回上一個資料夾」圖示加入眼睛標記，保留資料夾及方向符號，方便與「開啟資料夾」區分。
- 三個資料夾瀏覽工具以分隔線自成一組，與開啟資料夾及排序工具區隔。
- 關閉「顯示子資料夾」時，隱藏上一層與返回按鈕，收合選單也同步隱藏；重新啟用時恢復顯示，並保存偏好。
- 更新淺色、深色文件圖示與中英文操作說明，補上導覽按鈕顯示及偏好保存的驗證。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。
