# PicView v0.1.16

- 取消獨立主工具列，將開啟資料夾、排序方式及排序方向整併到縮圖工具列，與資料夾標籤共用一列。
- 標籤列與開啟資料夾、開啟資料夾與排序工具之間加入分隔線，讓工具分組更清楚。
- 顯示日期、檔案總管／Finder 整合、語言與配色共用同一個「…」展開面板。
- 視窗過窄時，每個工具列只保留一個「…」入口，面板直接顯示放不下的工具。
- 縮放數值按鈕與滑桿成組收合，展開後維持原操作：滑桿直接調整，點數值按鈕才顯示數值輸入與恢復預設值按鈕。
- 圖片資訊狀態列移到單圖窗格底部，比圖時由共同比圖區顯示，持續跟隨作用中的圖片。
- 更新中英文操作說明與版面、收合面板及縮放控制回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
