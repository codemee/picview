# PicView v0.1.11

- 縮圖支援多選、範圍選取、全選與滑鼠框選；點擊空白處取消選取。
- 可跨標籤複製或搬移多個圖檔，遇到同名檔可選擇取代、保留兩者、略過或取消。拖曳停留在標籤上會切換標籤，停留在左右箭頭上會持續捲動，也可放入切換後的縮圖區。
- 多選縮圖可一次加入比圖，略過已顯示的圖片；同資料夾圖片共用可見標籤，並保留獨立檢視。
- 比圖圖片可拖曳排序，提供跟隨滑鼠的圖片預覽、虛線插入空位與即時順序預覽；工具列新增取消比圖。
- 改善比圖拖放與關閉窗格的更新效率；關閉到最後一張時，縮圖與單圖保持選取最後圖片。
- 載入比圖時顯示半透明遮罩與轉圈提示，點陣圖改在背景解碼。
- 檔案總管／Finder 整合、語言與配色收進主工具列右側「…」選單。
- 開啟資料夾對話框預設從目前資料夾的上一層開始。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
