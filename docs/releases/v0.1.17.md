# PicView v0.1.17

- 修正比圖區外框固定亮起的問題，輸入焦點只會標示在縮圖窗格或比圖區其中一方；個別比圖圖片仍保留作用中標示。
- 切換比圖窗格時，同步完成共用工具列與版面配置後再更新畫面，避免中間狀態造成閃動。
- 切換符合窗格的圖片時，直接套用最終 Fit 與捲動軸設定，避免先取消再恢復 Fit 造成畫面跳動。
- 避免重複套用相同的比圖工具列樣式，減少不必要的版面更新。
- 更新中英文操作說明，加入焦點切換與比圖切圖回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
