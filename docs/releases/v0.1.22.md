# PicView v0.1.22

本版本包含 v0.1.21 的圖片編輯功能，並修正桌面封裝與 macOS 驗證流程。

- 裁切：非比圖模式可拖曳八個邊角控點，即時調整圖片範圍。
- 馬賽克：Alt+M 啟用，拖曳矩形後放開滑鼠套用，支援連續框選、單圖與全螢幕；動畫會處理所有影格。
- 多層復原與重做：Ctrl+Z／Ctrl+Y 支援裁切、旋轉、鏡射與馬賽克，每次拖曳各算一步。
- 存檔：Ctrl+S 與 Ctrl+Shift+S 以原始解析度儲存結果；未存檔時切換或關閉，會提供跟隨介面語言的「儲存／不儲存／取消」提示。
- 背景色：Alt+B 開啟面板，方向鍵選色、Enter／空白鍵套用、Esc 取消，另支援 Tab、Shift+Tab、Home 與 End。
- 工具圖示：另存新檔使用雙磁片，馬賽克使用淺灰色方格；附上中英文、不同字級與模擬個資的文字測試圖片。
- 修正桌面冒煙測試：驗證旋轉後先復原，再測試比圖與關閉，避免停在未存檔提示；新增真實啟動器回歸測試。
- 修正 macOS 測試相容性：快捷鍵提示依平台原生格式驗證，並配合 macOS 訊息窗不顯示視窗標題的行為。

[完整的圖片編輯功能說明](https://github.com/codemee/picview/blob/main/README.md#裁切與馬賽克)

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面下載檔與 SHA-256 校驗碼會在 GitHub Actions 完成測試與建置後附加至本次發布。
