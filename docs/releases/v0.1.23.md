# PicView v0.1.23

- 新增「裁剪接合」工具：左右拖曳選取貫穿全高的直條，上下拖曳選取貫穿全寬的橫條；依拖曳方向即時切換半透明預覽，放開滑鼠後移除區域並直接接合兩側原始像素。
- 裁剪接合支援連續操作、多層復原與重做、原始解析度存檔、動畫所有影格與全螢幕。Esc 可取消範圍或關閉工具；與裁切、馬賽克互斥，僅在非比圖模式啟用。SVG 套用後以點陣內容儲存。
- **快捷鍵調整：Alt+C 改為裁切，Alt+J 切換裁剪接合；旋轉由 Alt+C 改為 Alt+R。** 工具提示、中英文文件與全螢幕提示同步更新。
- 單圖工具列將存檔與另存新檔移至左側、自成一組；背景色移至右側 Fit 前方。
- 移除單圖工具列的重複檔名，統一在狀態列顯示檔名及未存檔星號；比圖工具列保留「比圖模式」標示。
- 修正左右並排與窄窗格時，縮放滑桿擠到面板邊框的問題；依數值按鈕實際最小寬度配置留白，數值文字改變時也會重新排版。
- 裁剪接合圖示使用上下圖片輪廓、中央虛線矩形與加號，並補上淺色／深色文件圖示。
- 新增方向即時切換、反向拖曳、縮放座標、像素接合、透明度、動畫、SVG、復原存檔、狀態列標記與快捷鍵相容測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面下載檔與 SHA-256 校驗碼會在 GitHub Actions 完成測試與建置後附加至本次發布。
