# PicView v0.1.21

- 新增非比圖模式的裁切工具，透過四角與四邊共八個控點即時裁切，原始檔在存檔前不會變更。
- 新增馬賽克工具與 Alt+M 快捷鍵，拖曳矩形並放開滑鼠即可套用，可連續處理多個範圍，支援單圖與全螢幕。動畫會處理所有影格；SVG 套用馬賽克後，以點陣內容存入 SVG。
- Ctrl+Z／Ctrl+Y 可多層復原與重做裁切、旋轉、鏡射及馬賽克；每次控點拖曳或矩形框選各算一步。
- 新增存檔（Ctrl+S）與另存新檔（Ctrl+Shift+S），以原始解析度儲存目前修改，另存後切換至新檔案，並保留編輯歷史。
- 檔名以星號標示未存修改；切換圖片、資料夾、標籤或關閉時提供「儲存／不儲存／取消」，取消或儲存失敗時保留修改。提示按鈕跟隨程式語言。
- PNG、GIF、WebP 與 TIFF 可保留多影格；轉存 JPEG／BMP 前會提示只儲存目前影格。存檔先寫入暫存檔，成功後替換目標檔，並對 Windows 暫時占用檔案的情況提供有限次重試。
- Alt+B 開啟背景色面板並聚焦目前顏色；方向鍵選色、Enter／空白鍵套用、Esc 取消，另支援 Tab、Shift+Tab、Home 與 End，單圖、比圖及全螢幕皆可使用。
- 另存新檔採雙磁片圖示，馬賽克採淺灰色方格；更新中英文操作文件與圖示，加入包含中英文、不同字級與模擬個資的馬賽克測試圖片及相關回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。
