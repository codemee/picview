# PicView v0.1.25

- 支援大型印刷 JPG：提高有上限的像素檢查範圍，並保留大型灰階圖片的灰階資料，降低記憶體用量。
- 改善大圖縮放與平移：僅繪製可見範圍，使用共用的多級預覽快取（上限 128 MiB），在背景產生畫面並只套用最新請求；停止操作後補上精細畫面。單圖、比圖與全螢幕共用此機制，編輯與存檔保留原始解析度。
- 透明圖片採分段縮小，避免為了顯示可見區域而複製整張原圖；關閉或切換圖片後釋放不再使用的原始資料。
- 改善 Windows UNC 路徑與網路磁碟機的讀取：背景掃描目錄並重用檔案資訊，避免主介面重複逐檔查詢；圖片與縮圖共用傳輸快取（上限 64 MiB），減少重複下載。
- 網路資料夾每 5 秒在背景檢查更新，暫時斷線或讀取失敗時保留已顯示內容，恢復連線後可繼續更新；快速換圖會捨棄過期結果，並支援 SVG 更新與檢視狀態還原。
- 新增大圖像素正確性、透明度、記憶體上限與釋放、背景工作排程，以及網路延遲、斷線恢復、傳輸去重、檢視狀態還原等測試；同步更新中英文文件。

## Platform support

大圖顯示改善為跨平台共用。**本版網路磁碟最佳化目前僅啟用於 Windows UNC 路徑與網路磁碟機。macOS 掛載於 `/Volumes/...` 的 SMB 磁碟仍使用一般讀取流程，尚未啟用這項網路最佳化。**

Large-image rendering improvements are shared across platforms. Network-drive optimizations currently activate only on Windows UNC paths and mapped network drives; macOS SMB mounts under `/Volumes/...` still use the standard loading path.

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面下載檔與 SHA-256 校驗碼會在 GitHub Actions 完成測試與建置後附加至本次發布。
