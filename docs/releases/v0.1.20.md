# PicView v0.1.20

- 新增非比圖模式的子資料夾瀏覽：黃色資料夾卡片排在圖片之前，單擊選取、雙擊在目前分頁進入。
- 提供「顯示子資料夾」開關並保存偏好，只列出直接子資料夾，不遞迴掃描圖片或產生資料夾封面。
- 新增「上一層資料夾」與「返回上一個資料夾」，依分頁保存本次瀏覽紀錄，返回時還原選圖、縮放與捲動位置。
- 比圖模式隱藏資料夾卡片與瀏覽工具；資料夾不參與圖片的多選、複製、拖曳或比圖操作。
- 排序方向圖示加入 A–Z／Z–A，返回與上一層採用黃色資料夾搭配方向箭頭，避免混淆。
- 應用程式圖示的資料夾改用暖黃色，同步更新 SVG、透明 PNG 與多尺寸 ICO。
- 更新中英文操作說明、工具圖示與 PyPI 可用的絕對連結，補上資料夾瀏覽、返回狀態、設定保存及圖片跨列導覽測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面下載檔與 SHA-256 校驗碼會在 GitHub Actions 完成測試與建置後附加至本次發布。
