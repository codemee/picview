# PicView v0.1.14

- Windows 啟動時設定固定的 PicView 應用程式識別碼，讓工作列正確識別與分組，改善從 Python 啟動時沿用 Python 圖示的情況。
- Windows 視窗改用包含多種尺寸的 ICO 圖示；macOS 維持原本的 PNG 圖示。
- 新增 Windows 工作列識別碼回歸測試。

已釘選的舊捷徑若仍顯示舊圖示，請取消釘選後從新版 PicView 視窗重新釘選；更新程式不一定會清除 Windows 的既有捷徑圖示快取。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
