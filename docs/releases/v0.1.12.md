# PicView v0.1.12

- 進入比圖模式後，共用工具列顯示加粗的「比圖模式」，個別圖片窗格保留檔名；退出後恢復單圖檔名。
- 比圖區加上主題強調色細框與淡色工具列背景，讓比圖模式更容易辨識，並隨深淺配色更新。
- 修正主工具列右側「…」按鈕切換到深色配色後仍沿用黑色圖示的問題。
- 更新中英文操作說明，補上比圖模式的外觀標示。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
