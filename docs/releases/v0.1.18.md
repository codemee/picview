# PicView v0.1.18

- 縮放比例與縮圖大小控制移至各窗格右下角的半透明面板，滑鼠移入時顯示、移出時隱藏；仍可輸入精確數值與重設大小。
- 比圖模式只保留一個共用縮放面板，固定於整個比圖區右下角，操作目前選取的圖片。
- 開啟同步操作時，先以選取圖片的實際縮放比例對齊所有比圖圖片；一般與全螢幕比圖皆適用。
- 取消比圖後，滑鼠若仍在單圖窗格內，縮放面板會立即恢復顯示。
- 「取消比圖」與「同步操作」獨立成組，非比圖模式不顯示同步按鈕。
- 背景色按鈕直接預覽目前顏色；比圖時變更背景色會套用到所有參與比圖的圖片，不受同步開關影響。
- 更新中英文操作說明與背景色按鈕圖示，補上浮動面板、模式切換與初始同步縮放的回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
