# PicView v0.1.15

- 新增常駐圖片資訊狀態列，顯示檔名、像素尺寸、格式、檔案大小及資料夾內序號。
- 比圖模式下，狀態列跟隨作用中圖片更新；圖片修改後也會更新尺寸等資訊。
- 狀態列 tooltip 提供完整路徑與圖片資訊，並明確設定主題文字與背景色，修正提示文字無法辨識的問題。
- 狀態列納入主版面配置，與窗格共用左右邊界及留白，文字在寬窄視窗下皆保持於狀態列範圍內。
- 原有刪檔等通知可暫時取代圖片資訊，通知結束後恢復顯示。
- 更新中英文操作說明與狀態列回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
