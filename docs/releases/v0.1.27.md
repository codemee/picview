# PicView v0.1.27

- 將資料夾開啟、瀏覽、排序及設定工具移至主視窗頂部，橫跨整個視窗；工具列直接融入背景，移除白色圓角底框。
- 資料夾標籤列保留在縮圖窗格內，左側仍可拖曳調整窗格排列；主視窗工具列不再包含窗格拖曳手把。
- 主視窗與單圖工具列按鈕、縮圖標籤列統一採用 28 px 精簡高度，減少 hover 灰底的內距、圓角與上下留白；比圖的共用圖片工具也同步調整。
- 主工具列與縮圖標籤列各自處理可用寬度，左右並排或縮窄縮圖窗格時，主工具列仍可使用整個視窗的寬度。
- 修正首次排版尚未完成就切換窗格方向時，可能沿用暫時尺寸而造成比例失衡的問題。
- 更新中英文文件與排版、收合、分頁及拖曳測試；文件明確說明顯示子資料夾為全域設定，排序方式及方向則由各分頁保存。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面下載檔與 SHA-256 校驗碼會在 GitHub Actions 完成測試與建置後附加至本次發布。
