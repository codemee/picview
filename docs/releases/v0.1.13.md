# PicView v0.1.13

- 圖片放大至可捲動時，可用滑鼠左鍵拖曳平移；一般視窗、單圖全螢幕及比圖全螢幕皆支援。
- 縮圖與單圖窗格以框線標示輸入焦點，框線使用與滑桿手把相同的主題強調色。
- 縮放快捷鍵依焦點調整縮圖大小或圖片比例：<kbd>+</kbd>、<kbd>-</kbd>、<kbd>0</kbd>，亦支援 <kbd>Ctrl</kbd> 組合鍵；macOS 使用 <kbd>Command</kbd>。支援修飾鍵搭配滑鼠滾輪縮放。
- 全螢幕也支援縮放快捷鍵，並修正 <kbd>Alt</kbd>+<kbd>F</kbd> 無法切換符合畫面的問題。
- 全螢幕捲軸改用與主視窗一致的現代扁平樣式。
- 更新中英文操作說明與互動回歸測試。

## Downloads

- Windows x64：解壓 ZIP，保留完整 PicView 資料夾後執行 PicView.exe。
- macOS Apple Silicon：開啟 DMG，將 PicView.app 拖到 Applications。
- Python：`uv tool install --upgrade picview`。

桌面安裝檔由 GitHub Actions 建置完成後附加至本次發布。
